# Tervexa

An AI-powered technical intelligence platform for field service engineers, technicians, application specialists, technical managers and other technical professionals.

Submit fault reports, installation records, after-sales cases and application support requests. Get AI analysis with photo recognition, track resolutions, and build a searchable history of what actually fixed what.

Built with HTML, CSS, JavaScript, Node.js, Express and SQLite. Uses the Anthropic API for diagnosis and chat.

Work in progress.
